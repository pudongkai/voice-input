VoiceInput

适用于所有编辑器、终端等的语音输入工具

下载

请先在 GitHub Release 页面 下载最新的 .dmg 或 .zip 包。

  • VoiceInput-1.1.6.dmg
  • VoiceInput-1.1.6.zip

安装后直接拖入 /Applications 即可使用。

主要特性

  • 原生 macOS 菜单栏 App，无需任何运行时依赖
  • 使用系统自带的 Apple 语音识别（免费、无需 API Key）
  • 支持本地离线模型，隐私安全
  • 透明度可调，实时预览
  • 粘贴或键盘输入两种模式，自由切换
  • 开机自启动、配置热加载

快速使用

  1. 安装后打开 VoiceInput.app（首次需要授权麦克风、语音识别、辅助功能）
  2. 在任意编辑器/终端光标处按住 右 Option（⌥），说话后松开即可自动输入文字
  3. 可在菜单栏图标中调节透明度、开启/关闭开机启动、切换输入方式等

常见问题

为什么需要授权辅助功能？
辅助功能是 macOS 用来让第三方程序模拟键盘或粘贴的权限，只要授权一次即可。
如何保持剪贴板内容？
在设置页面把 restoreClipboard 设为 false，识别结果会保留在剪贴板。
