VoiceInput 语音输入（macOS 13+）
================================

一句话：按住右 Option 说话，松开后文字自动输入到当前输入框。
OpenCode、Claude Code、任何编辑器或聊天框都能用。


安装
----
1. 把 VoiceInput 拖到旁边的「Applications（应用程序）」文件夹。

2. 第一次打开：
   在「应用程序」里右键 VoiceInput → 打开。
   如果提示“无法验证开发者”：
   打开 系统设置 → 隐私与安全性 → 找到 VoiceInput → 点「仍要打开」。

   如果仍然打不开，在终端执行：
   xattr -dr com.apple.quarantine /Applications/VoiceInput.app
   然后重新打开。

3. 菜单栏出现麦克风图标后，点击它，依次授权：
   - 麦克风
   - 语音识别
   - 辅助功能（系统设置 → 隐私与安全性 → 辅助功能 → 打开 VoiceInput）

   授权辅助功能后，App 会在 2 秒内自动生效。

4. 首次启动会自动加入「登录项」，也就是开机启动。
   不想开机启动的话，在菜单里点一下「开机启动（已开启）」关闭即可。


使用
----
1. 光标点进 OpenCode / Claude Code 的输入框。
2. 按住右 Option（⌥），底部出现“正在聆听…”。
3. 说一句话，松开。
4. 文字自动出现在输入框，按回车发送。


常见问题
--------
Q: 按住右 Option 没反应？
A: 检查 系统设置 → 隐私与安全性 → 辅助功能 里的 VoiceInput 是否打开；
   如果显示未授权，点菜单里的「辅助功能：未授权」，会自动清理旧授权并打开设置页，
   重新把 VoiceInput 的开关打开即可；
   如果还不行，把列表里的旧 VoiceInput 用「-」删掉，再点「+」添加 /Applications/VoiceInput.app。

Q: 识别不准？
A: 系统设置 → 键盘 → 听写，开启并添加「中文（普通话）」，
   下载离线语言包后准确率更高，也可以完全离线。
   还可以编辑 ~/.config/voice-input/config.json 里的 contextualStrings，
   加入你常用的项目名、框架名。

Q: 剪贴板里的内容被改了？
A: 默认的「模拟键盘输入」不会动剪贴板。如果你在菜单里把输入方式换成了「粘贴」，
   识别出的文字会同时复制到剪贴板，方便再次粘贴。不想这样的话，
   点菜单栏的麦克风图标 →「输入方式」→ 选回「模拟键盘输入」。

Q: 支持 Intel Mac 吗？
A: 支持。安装包是 Universal 二进制（arm64 + x86_64），需要 macOS 13 及以上。

Q: 为什么第一次打开有安全提示？
A: 这个 App 使用本地 ad-hoc 签名，没有购买 Apple 开发者证书做公证。
   不影响使用；右键「打开」即可。

Q: 怎么卸载？
A: 菜单栏 → 退出 VoiceInput，然后把 /Applications/VoiceInput.app 删除。
   如果开过机启动，先在菜单里取消「开机启动」。


配置文件：~/.config/voice-input/config.json
日志文件：~/Library/Logs/VoiceInput.log
